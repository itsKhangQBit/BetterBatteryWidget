# BetterBatteryWidget
https://www.opendesktop.org/p/2355937/

Just a simple battery widget, for Plasma.

**PLEASE RESTART PLASMASHELL, OTHERWISE IT MIGHT NOT WORK!**

**A lightweight,** ~minimal~ (not minimal anymore ig) **battery widget for KDE Plasma 5 / 6. I find the default widget not that good, so I decided to create a new one**.

### **Features:** 
- Battery percentage and battery saver (minimum ahh feature)
- Percentage font, styles (Bold, Italic, Underline), size, position, color, charge indicator and feature customizations, both on panel and in the applet popup
- Battery icon size, rotation (vertical / horizontal)
- Sleep block & list of apps blocking sleep
- Time remaining (charge / discharge)
- Battery health
- Periperal battery levels
- ~2763 options~ A lot of options

### **Help translating this project:**

If you like to contribute to my repository then this might be the fastest way to do it, more languages are welcome!
- The **best way to translate is going to my translation project (https://translate.codeberg.org/projects/betterbatterywidget_plasma/languages/) and make a translation there**. Once done you can download your translation file and open a pull request with your file.

- Or if you like to do it the "classic" way:

- - Clone this repository (I assume you know how to clone repositories... okay fine: `git clone https://github.com/itsKhangQBit/BetterBatteryWidget/`)
- - Go to the "translate!" directory and find the file "template.pot"
- - Open it in any editor you like, it's just text (e.g. Kate, Lokalize, ...)
- - Fill in your language (and your name or email if you like, if you don't I'll just take your Github username for contribution)
- - Translate the strings
- - Once done, save the file as "[your locale].po"
- - Open a pull request and I'll happily merge it!
